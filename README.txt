# Meu Treino
Aplicativo web para celular com os treinos de segunda, quarta, quinta e sábado.

Recursos:
- exercício + foto real carregada online
- séries e repetições
- campo editável de peso em kg por série
- marcação de série concluída
- progresso do treino
- salvamento automático no próprio celular (localStorage)
- botão para zerar o treino do dia

Como usar:
1. Abra index.html no navegador.
2. No celular, use "Adicionar à tela inicial" / "Instalar aplicativo", quando disponível.
3. As fotos precisam de internet para carregar.
